# Mi portafolio personal

Portafolio personal desarrollado con React, TypeScript y Vite.

En este proyecto presento información sobre mí, las tecnologías que estoy aprendiendo y uno de los proyectos que he realizado durante el módulo 03.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- TypeScript
- React
- Vite

## Componentes

El portafolio está construido con varios componentes de React:

- `Presentacion`: muestra mi nombre y una descripción sobre mis intereses.
- `ListaTecnologias`: recibe una lista de tecnologías mediante props y las muestra usando `map()`.
- `ListaProyectos`: recibe una lista de proyectos mediante props y genera una tarjeta para cada proyecto usando `map()`.

También existe una sección de contacto con un enlace de correo electrónico.
